TITLE
Traceon: prove the cause before you recall (Open Agent Hackathon 2026, Track 02)

DESCRIPTION
Traceon is an AI agent for product-safety teams. When products start catching fire, it finds the root cause, proves why every other explanation is wrong, and only then lets a named person act on the exact units at risk.

Every test is a SQL query on Zetaris. Meterless H-MEM converges the weak signals; Meterless Nightshift is the AI provider, routing to NVIDIA Nemotron. The model plans, attacks and explains; it never computes a statistic. Every step is hashed into a proof chain anyone can replay.

Everything in this film is real: the live app at traceon.netlayerlabs.com (Zetaris live, with a hash-parity check), a run on a Mac through Meterless Nightshift, public NHTSA complaints and recalls for the Chevrolet Bolt EV, and Backblaze Drive Stats for Q2 2026. The VoltRide reference case is a simulated company and is labelled as such.

Try it: https://traceon.netlayerlabs.com
Code: https://github.com/NetLayerLabs/Traceon
Judge it offline in one command: ./sample.sh

Sources
NHTSA complaints and recalls (api.nhtsa.gov): complaints 11372429 and 11426342, recalls 20V701000 and 21V560000
Backblaze Drive Stats: https://www.backblaze.com/cloud-storage/resources/hard-drive-test-data

Built for the Open Agent Hackathon 2026 (GenAI.works), Track 02: The Agent That Can Explain Why, by NetLayer Labs. With Zetaris, Meterless, NVIDIA Nemotron and Bright Data.
